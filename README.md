# 🛒 ShopMe - E-Commerce Web App

A fully functional frontend e-commerce application built with React, Redux Toolkit, and Tailwind CSS.

## 🚀 Tech Stack
- React 18
- Redux Toolkit
- React Router v6
- Tailwind CSS
- Axios
- DummyJSON API

## ✨ Features
- Browse 100+ products by category
- Add to cart with quantity controls
- Persistent cart via localStorage
- User authentication (signup/login)
- Checkout with order placement
- Dark mode support
- Fully responsive design

## 🛠️ Run Locally
npm install
npm run dev
